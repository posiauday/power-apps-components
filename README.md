# Power Apps components

Free, copy-paste components for Power Apps canvas apps, from [LowCodeStacks](https://lowcodestacks.com/components). Each folder has the component's YAML and the steps to paste it into Power Apps Studio. Every component is paste-tested in Studio before it's published.

| Component | Version | On the site |
| --- | --- | --- |
| [Button](button/) | 0.3.0 | [Live demo and guide](https://lowcodestacks.com/components/button) |
| [Floating action button](floating-action-button/) | 0.3.0 | [Live demo and guide](https://lowcodestacks.com/components/floating-action-button) |
| [Stepper](stepper/) | 0.3.0 | [Live demo and guide](https://lowcodestacks.com/components/stepper) |
| [Tree view](tree-view/) | 0.2.0 | [Live demo and guide](https://lowcodestacks.com/components/tree-view) |

The site has more: a live preview of each component with every property, variations, the guide and its change log. Some components need a free sign-in to copy there, and aren't in this repository.
